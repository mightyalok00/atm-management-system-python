# ATM Management System - Clean Version

This version is prepared for Windows and `D:\` drive extraction.

## Run

Recommended:

```text
run_atm.bat
```

Or from PowerShell:

```powershell
cd "D:\ATM_Management_System_Clean"
python -B main.py
```

`-B` prevents Python from creating `.pyc` files and `__pycache__` folders.
