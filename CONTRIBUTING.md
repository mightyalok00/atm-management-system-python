# Contributing

Contributions that improve correctness, tests, documentation, or accessibility are welcome.

1. Fork the repository and create a focused branch.
2. Install the project requirements.
3. Run `python -B -m unittest discover -s tests -v`.
4. Keep changes small and document user-visible behavior.
5. Open a pull request describing the problem, solution, and verification performed.

Do not include real credentials, PINs, account details, or personal banking data in issues, tests, or pull requests.
